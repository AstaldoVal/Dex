# Match Club: очередь шаблонных сообщений (автоотправка при экспорте)

Список сообщений **по порядку**: при нажатии в боковой панели **«Экспорт всех чатов в JSON (на диск)»** расширение подставляет в каждый открытый чат **следующее** сообщение из очереди по правилам ниже.

**Источник очереди:** если в этом файле **нет** ни одного пункта списка (ниже пусто или только текст без `- ` / `1. `), `GET /api/match-club-outbound-queue` берёт **тот же** нумерованный список EN, что и промпт: `chat-followup-phrases-approved-en.md`, секция **English**. Отдельного «примера» здесь нет — правда одна. В ответе API: `queueSource: approved_followup` или `match_club_file`. Если файла очереди не существовало и approved тоже недоступен, сервер создаёт этот файл с пояснением и снова проверяет.

Расширение не подставляет фразы из кода — только через сервер. В JSON экспорта смотрите `outboundRun` и `queueSource` у сервера.

**По умолчанию (фаза контроля):** текст только попадает в поле ввода; скрипт ждёт, пока вы **отправите сообщение вручную**, затем переходит к следующему чату. Снимите галочку «только вставка…» в панели, чтобы снова включить автоматическую отправку без ожидания.

**Файл редактируется вручную.** Поддерживаются:

- Маркированный или нумерованный список Markdown (строки с `- `, `* ` или `1. `).
- Либо один JSON: массив строк или объект `{ "messages": ["...", "..."] }`.

## Логика на один чат

1. **Пустой тред** — отправляется первое сообщение очереди.
2. **Последнее сообщение от собеседника** — ничего не отправляется (вы отвечаете сами).
3. **Последнее от вас** совпадает с пунктом очереди с индексом `N` (точное совпадение текста после нормализации пробелов) — отправляется пункт `N+1`.
4. **Последнее от вас** не совпадает ни с одним пунктом очереди — чат пропускается (ручная обработка).
5. **Последнее от вас** совпадает с **последним** пунктом очереди — пропуск (цепочка завершена для этого шаблона).

Если роль последнего сообщения не удалось определить (`unknown`), чат пропускается с записью в лог.

## Режим только вставки (по умолчанию)

Успешное продолжение: в треде появилось **новое** исходящее сообщение (`role: me`). Таймаут ожидания по умолчанию 10 минут на чат (`timeout_waiting_manual_send` в логе при истечении).

## Где смотреть результат

- Полный JSON экспорта: `match-club-snapshots/match-club-chats-export-*.json` — у каждого чата поле `outbound` (отправлено / пропуск / ошибка).
- Если очередь была непустой: дополнительно `match-club-snapshots/match-club-outbound-run-*.json` и запись в `match-club-outbound-runs.md`.

## Своя очередь

Заполняйте **только** если для экспорта нужны не те строки или не тот порядок, что в `chat-followup-phrases-approved-en.md`. Иначе секцию оставьте пустой (см. «Источник очереди» выше). Формат: markdown-список или JSON, как в начале файла.
