Readiness score R (0–100)

x = B + A + Pill + Palc

R is the integer from 0 to 100 obtained by rounding x to the nearest integer; if that value is below 0, use 0; if above 100, use 100.

Definitions and step-by-step formulas

Quantities

  • Q, E, N: sleep quality, energy, nutrition (questionnaire; typically 0–10, default 5 if missing).
  • s̄: mean muscle-soreness intensity over logged zones (default 1 if none).
  • τ ∈ {2, 5}: tension score (2 if no posture tension logged, 5 otherwise).
  • σ, μ, φ: stress, mood, mental fatigue (typically 1–10; default 5 if missing).

Weighted inner sum

inner = 0.30·Q + 0.25·E + 0.20·(10 − 3s̄) + 0.15·(10 − τ) + 0.10·N

Base on the 0–100 scale

B = 10 · inner

Psych adjustment

A = ((5 − σ) + (5 − μ) + (5 − φ)) / 3 · 2.2

Penalties

Pill ∈ {0, −18} (illness active or not).  Palc ∈ {0, −2, −5, −10} by alcohol units.
