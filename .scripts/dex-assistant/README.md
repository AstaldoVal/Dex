# Dex Assistant

Помощник с аватаром в правом нижнем углу экрана, озвучивающий свои действия (TTS).

## Возможности

- Окно с аватаром в правом нижнем углу (всегда поверх, не забирает фокус)
- **Виджет Job Search:** пункт меню «Виджет Job Search» (⌘J) открывает плавающее окно с **нативным** выводом (как в терминале): статус последних прогонов, время запуска и лог. Браузер не запускается. Сервер API должен быть запущен: `npm run job-search:widget` в репозитории Dex (сервер тоже больше не открывает браузер).
- Настраиваемый аватар: своя картинка (PNG, JPG, GIF), в т.ч. аниме-стиль
- **Видео-аватар (как iStripper, но SFW):** выбери **видеофайл** (MOV или MP4) — персонаж непрерывно проигрывается в цикле, без звука. Подойдут любые короткие зацикленные ролики: desktop mascot, аниме-персонаж, Live2D-экспорт и т.п.
- **Движение по экрану (wander):** в меню включи «Движение по экрану (wander)» — аватар плавно ходит вдоль нижнего края экрана (туда-обратно)
- **Жестикуляция / idle-анимация:** выбери **папку** с кадрами (idle_1.png, idle_2.png, …). Кадры переключаются по кругу ~5 раз в секунду
- Озвучивание фраз системным голосом (русский по умолчанию)
- Очередь: если отправить несколько фраз подряд, они озвучатся по очереди
- При озвучивании аватар слегка пульсирует

## Сборка

```bash
npm run assistant:build
# или
bash .scripts/dex-assistant/build.sh
```

Требуется Xcode Command Line Tools (`xcode-select --install`).

После сборки: `open .scripts/dex-assistant/build/DexAssistant.app`

**Где меню:** **Правый клик (или Control+клик) по блоку с аватаром** или клик по иконке в строке меню — «Выбрать аватар…», «Сказать…», «Сбросить аватар», «Движение по экрану (wander)», **«Виджет Job Search»** (⌘J), «Выход».

**Пошаговая инструкция «Аватар через SeaArt»:** см. [AVATAR-VIA-SEAART.md](AVATAR-VIA-SEAART.md) — создание аватара в SeaArt.ai и подстановка в приложение.

## Настройка аватара

1. Запустите DexAssistant.app (блок с аватаром появится справа внизу)
2. **Правый клик по блоку** → «Выбрать аватар…»:
   - **Видео (MOV/MP4)** — зацикленное видео персонажа (двигается постоянно, без звука). Идеально для эффекта «desktop mascot» как у iStripper, но SFW.
   - **Один файл** — PNG/JPG/GIF (статичный аватар)
   - **Папка** — папка с PNG/JPG-кадрами (idle_1.png, idle_2.png …). Кадры проигрываются по кругу (жестикуляция / idle)
3. «Сбросить аватар» — вернуть иконку по умолчанию
4. «Движение по экрану (wander)» — включить/выключить плавное движение окна вдоль нижнего края экрана

Рекомендуемый размер кадра: 120×120–256×256 px, с прозрачностью для PNG. Для видео — короткий цикл 5–30 сек, квадрат или вертикаль, можно с прозрачностью (MOV ProRes 4444) или с фоном.

**Где взять SFW видео для аватара:** зацикленные ролики «desktop mascot», «live2d idle», «anime character loop» на YouTube (конвертировать в MP4); готовые паки на Wallpaper Engine (Steam) или в сообществах VTuber/Live2D; экспорт из Live2D Cubism или из Blender.

## Отправка фраз на озвучку

Пока приложение запущено, фразы можно передавать так:

- **Из терминала:**  
  `npm run assistant:say -- "Проверяю календарь"`  
  или  
  `echo "Готово" | node .scripts/dex-assistant-say.cjs --stdin`

- **Из скриптов/MCP:** записать текст в файл  
  `~/Library/Application Support/DexAssistant/action.txt`  
  Приложение следит за файлом и озвучивает новое содержимое.

Пример из скрипта:

```javascript
const path = require('path');
const os = require('os');
const fs = require('fs');
const actionPath = path.join(
  os.homedir(), 'Library', 'Application Support', 'DexAssistant', 'action.txt'
);
fs.writeFileSync(actionPath, 'Обработка завершена.', 'utf8');
```

## Файлы и папки

- Приложение: `.scripts/dex-assistant/build/DexAssistant.app`
- Конфиг/очередь: `~/Library/Application Support/DexAssistant/`
- Путь к аватару хранится в UserDefaults приложения (после «Выбрать аватар»)

## Виджет Job Search

В меню приложения есть пункт **«Виджет Job Search»** (⌘J). Он открывает плавающее окно с **нативным** выводом (моноширинный текст, как в терминале): статус последнего прогона (incremental, iGaming, full), время запуска, сводка и полный лог последнего запуска. Браузер не используется и не открывается.

**Важно:** панель запрашивает данные с `http://127.0.0.1:8766/api/status`. Запустите в репозитории Dex сервер: `npm run job-search:widget` (браузер при этом не откроется). Если сервер не запущен, в окне будет подсказка «Запустите npm run job-search:widget».

## Автозапуск (по желанию)

Чтобы Dex Assistant запускался при входе в систему:

1. Системные настройки → Основные → Объекты входа в систему
2. Добавить программу: `.scripts/dex-assistant/build/DexAssistant.app`
