# DexSpeak — приложение для озвучки текста (macOS)

Автономное приложение для macOS: плавающий виджет озвучки с OpenAI TTS (русский без акцента) или системным голосом.

## Установка

1. **Собрать из исходников** (нужны Xcode Command Line Tools):
   ```bash
   cd .scripts/speak-widget/DexSpeakApp
   ./build.sh
   open build/DexSpeak.app
   ```

2. **Создать DMG для распространения** (один файл для скачивания):
   ```bash
   ./build.sh
   ./create-dmg.sh
   # Результат: build/DexSpeak-1.0.0.dmg
   ```
   Пользователь скачивает DMG, открывает, перетаскивает DexSpeak в папку «Программы».

## Первый запуск

При первом запуске приложение запросит **OpenAI API ключ** (для голосовой модели). Ключ сохраняется в связке ключей macOS и больше не запрашивается. Изменить ключ можно в меню: «Настройки (API ключ)…».

## Использование

- Иконка в строке меню (🔊).
- **Озвучить буфер обмена** — озвучить текст из буфера обмена (русский → OpenAI TTS, иначе системный голос).
- **Озвучить файл…** — выбор текстового или PDF файла.
- Во время воспроизведения появляется плавающее окно с паузой и остановкой (как в виджете Dex).

## Требования

- macOS 12+
- Для русского текста — OpenAI API ключ (модель tts-1-hd, голос nova).
