# Dex Speak Widget (Swift)

Небольшое плавающее окно для индикации озвучивания и кнопки «Остановить».

- Появляется только когда начинается воспроизведение (не при запуске процесса).
- Плавающее окно (NSPanel), не перехватывает фокус.
- Анимированный индикатор (пульсирующий круг).
- Кнопка «Остановить» создаёт флаг и запускает `npm run speak-stop`.
- Автоматически закрывается, когда процесс озвучивания завершается.

## Сборка

```bash
./build.sh
# или из корня репозитория:
npm run speak-widget:build
```

Требуется: Xcode Command Line Tools (`xcode-select --install`).

## Использование

Скрипт `speak-report.cjs` сам запускает виджет при начале воспроизведения, если найден бинарник `DexSpeakWidget` в этой папке. Если бинарника нет, используется fallback на AppleScript (диалог).

## Standalone-приложение (DexSpeak.app)

В папке `DexSpeakApp/` собрано автономное приложение для macOS: один .app (или DMG) для установки без Node/Dex.

- **Первый запуск:** запрос OpenAI API ключа, сохранение в связку ключей.
- **Меню в строке меню:** озвучить буфер обмена, озвучить файл, настройки (API ключ).
- Во время воспроизведения — тот же плавающий виджет (пауза/стоп).

Сборка и DMG для распространения:

```bash
npm run speak-app:build   # → build/DexSpeak.app
npm run speak-app:dmg    # → build/DexSpeak-1.0.0.dmg (один файл для скачивания)
```

Подробнее: `DexSpeakApp/README.md`.
