# Перезагрузка расширения после изменений

После изменения файлов расширения нужно перезагрузить его в Chrome:

1. Откройте `chrome://extensions/`
2. Найдите "Dex LinkedIn Job Capture"
3. Нажмите кнопку обновления (🔄) или переключите расширение выключить → включить
4. Обновите страницу с дайджестом (F5)

Расширение готово к работе.
