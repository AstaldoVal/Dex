# Фильтр ошибок консоли для Dex расширения

LinkedIn и другие расширения генерируют множество ошибок в консоли. Чтобы видеть только ошибки нашего расширения Dex:

## Рекомендуемый фильтр (скрывает ошибки LinkedIn и других расширений)

В поле **"Filter"** консоли Chrome введите:

```
-sdui -web-client-content-script -main.min.js -utag.js -chrome-extension://invalid -stickyadstv -6xit43scc04ns3vx47p7zv81u -4ld68pfe71p01nusw3s7m8m9j -ep7lv466vmkjzvje2yk243it4
```

Это скроет:
- Ошибки LinkedIn (`sdui`, `main.min.js`, `utag.js`)
- Ошибки других расширений (`web-client-content-script`, `chrome-extension://invalid`)
- Ошибки рекламных скриптов (`stickyadstv`, различные хешированные файлы)

И покажет только ошибки нашего расширения Dex (если они есть).

## Альтернативный фильтр (только наши файлы)

Показать только ошибки из файлов нашего расширения:

```
content.js|digest-page.js|dex
```

## Фильтр для конкретного расширения по ID

Если знаете ID проблемного расширения:

1. Откройте консоль Chrome (F12)
2. Найдите ошибку от расширения (например, `chrome-extension://invalid/`)
3. Посмотрите на ссылку справа от ошибки — там будет ID расширения (например, `5fdhwcppjcvqvxsawd8pg1n51:12260`)
4. Скопируйте ID расширения (часть до двоеточия)
5. В фильтре введите: `-5fdhwcppjcvqvxsawd8pg1n51`

## Показать только ошибки нашего расширения

Если знаете ID расширения Dex:

1. Откройте `chrome://extensions/`
2. Найдите "Dex LinkedIn Job Capture"
3. Скопируйте ID расширения
4. В фильтре введите: `chrome-extension://ID_DEX_РАСШИРЕНИЯ`
