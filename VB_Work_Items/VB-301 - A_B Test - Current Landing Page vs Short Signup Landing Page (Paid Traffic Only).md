## Description
Description:
Run an A/B test to evaluate the impact of a shorter, conversion-focused landing page for users coming from paid traffic sources.
The goal is to understand whether reducing content and showing a more direct signup experience improves signup conversion rate compared to the current landing page.
The test should only apply to users identified as paid traffic.

• Control keeps the current landing page experience
