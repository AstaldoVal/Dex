## Description
Description:
Currently, when a user clicks Verify on the Redeem page, a modal appears asking them to enter their first and last name before proceeding.
This modal is no longer required and should be fully removed.
The verification flow should start immediately after the user clicks Verify, without collecting or displaying any additional name input.
No other parts of the Redeem or KYC flow should be modified.
