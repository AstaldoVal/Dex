# skills_bundles (имя из плана)

Тонкий слой **индексируемых** Agent Skills для router-а лежит в репозитории здесь:

- **`.claude/skills/task-bundles/<category_id>/SKILL.md`** — 16 коротких пакетов (по одному на закрытый `category_id`).

Полные тексты PM, BMAD и доменных «коробок» не дублируются в этой папке: они в **`Skills_library/`** и подключаются через **`Read`** по карте **`.claude/reference/task-skill-bundles.md`**.

См. также **`Skills_library/README.md`** и **`06-Resources/Dex_System/cursor_agent_skills_discovery_one_page.md`**.
