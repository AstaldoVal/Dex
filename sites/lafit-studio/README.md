# LA Fit Studio, concept site

Static single page (no build step). Concept redesign, not the studio's official site; `noindex` is set on purpose.

Deploy to Vercel:

1. Vercel dashboard, Add New, Project, import `AstaldoVal/Dex`, branch `claude/project-thread-okjcl2`.
2. Root Directory: `sites/lafit-studio`. Framework preset: Other. No build command.
3. Deploy.

Or from a machine with the Vercel CLI: `npx vercel deploy sites/lafit-studio --prod`.

Booking buttons point to the studio's existing Gymcatch page (provider 10473) and WhatsApp.
