# Gmail MCP — Glorium (roman.matsukatov@gloriumtech.com)

Токен для **gmail-glorium-mcp**: после первого запроса к почте Glorium (например «покажи письма из Glorium») откроется браузер для OAuth; токен сохранится в `gmail_token.json` здесь.

Credentials: используется общий `credentials.json` из корня репо (тот же OAuth client).
