# Figma: получение структуры продукта и скриншотов по ссылке

Чтобы по ссылке на Figma-дизайн получать **полное описание продукта** (структура, текст, скриншоты фреймов), в Dex есть два пути.

---

## 0. Figma MCP в Cursor (подключён в проекте)

Figma добавлен в `.cursor/mcp.json.source` и при запуске `python3 .scripts/cursor-sync-mcp.py` попадает в `~/.cursor/mcp.json`.

**После полного перезапуска Cursor:**  
1. Cursor Settings → Features → MCP → в списке должен быть **figma**.  
2. При первом использовании нажми **Connect** рядом с Figma и пройди OAuth в Figma (Allow Access).  
3. После этого в чатах будут доступны инструменты Figma MCP по ссылке на фрейм/слой.

---

## 1. Figma API (рекомендуется): скрипт `figma_fetch_design.py`

Скрипт по ссылке на файл/узел:
- забирает структуру и текст из Figma REST API;
- при необходимости сохраняет PNG-скриншоты выбранных узлов.

### Настройка (один раз)

1. **Personal access token**
   - Figma → Settings → Personal access tokens.
   - Создать токен с scope **file_content:read**.

2. **Токен в окружении**
   - В корне репо в `.env` добавить:  
     `FIGMA_ACCESS_TOKEN=your_token`

### Запуск

Из корня репо:

```bash
# Одна ссылка (файл + опционально node-id)
python3 .scripts/figma_fetch_design.py "https://www.figma.com/design/FILE_KEY/...?node-id=1477-53238"

# Несколько ссылок (узлов) из одного файла
python3 .scripts/figma_fetch_design.py "URL1" "URL2"

# Сохранить markdown в файл и PNG в папку
python3 .scripts/figma_fetch_design.py "URL" --output 00-Inbox/Job_Search/figma-product.md --images 00-Inbox/Job_Search/figma-captures
```

**Вывод:**
- В stdout (или в `--output`) — markdown: имя файла, дерево узлов, имена слоёв, текст (TEXT nodes).
- С `--images` — в указанную папку сохраняются PNG по одному на узел (`node_id.png`).

### Поведение агента

Когда пользователь даёт ссылку на Figma-дизайн и просит понять продукт, описать экраны или подготовить описание опыта:

1. Запустить скрипт с этой ссылкой (и при необходимости с несколькими ссылками на узлы того же файла).
2. При наличии `FIGMA_ACCESS_TOKEN`: использовать вывод скрипта (структура + текст) и при необходимости `--images` для скриншотов.
3. Результат использовать для формулировок в резюме, описания продукта или ответа пользователю.

---

## 2. Fallback: браузер (скриншот страницы)

Если токен не настроен или скрипт недоступен:

1. Открыть ссылку в браузере (MCP cursor-ide-browser): `browser_navigate(url)`.
2. Подождать загрузки канваса: `browser_wait_for(time=5)`.
3. Сделать скриншот с сохранением в workspace:  
   `browser_take_screenshot(filename="00-Inbox/Job_Search/figma-screenshot.png")`.
4. Прочитать изображение: `read_file(path)` — инструмент поддерживает изображения.

По скриншоту можно описать видимый экран; структуру и текст из узлов так получить нельзя.

---

## Сводка

| Способ              | Структура + текст | Скриншоты узлов     | Требования        |
|---------------------|-------------------|----------------------|-------------------|
| `figma_fetch_design.py` | Да                | Да (PNG по node-id) | FIGMA_ACCESS_TOKEN |
| Браузер             | Нет               | Один скрин страницы | MCP browser       |

Для описания продукта по ссылке предпочтительно использовать скрипт и токен; браузер — запасной вариант.
