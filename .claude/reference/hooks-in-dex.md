# Hooks in Dex

**Что такое hooks:** автоматические сценарии, которые запускаются по событиям (старт сессии, после выполнения инструмента, перед действием). В Cursor поведение из CLAUDE.md выполняется вероятностно; в **Claude Code** (CLI или Desktop) hooks выполняются **гарантированно** при каждом срабатывании события.

**Где работают:** Hooks — фича **Claude Code** (code.claude.com, CLI, Desktop app). В Cursor hooks **не настроены и не описаны** в репозитории Dex: конфигурация и описание лежат в экосистеме Claude Code. В Dex можно лишь рекомендовать, для каких флоу они полезны, и вести список сценариев.

**Типы hooks (по документации Claude Code):**

- **SessionStart** — при открытии сессии (загрузка контекста: цели, приоритеты, срочные задачи).
- **PreToolUse** — перед вызовом инструмента (проверка, подтверждение, подстановка контекста).
- **PostToolUse** — после вызова инструмента (уведомление по завершении, экспорт перед компакцией, пост-обработка).
- **SessionEnd** / аналоги — при закрытии сессии (опционально экспорт состояния, сохранение контекста).

**Для каких флоу в Dex полезно настраивать hooks (рекомендации):**

1. **Уведомление по завершении длинного флоу**  
   После успешного завершения скрипта или скилла (например full LinkedIn→Teal flow, экспорт в Linear, генерация дайджеста) — PostToolUse или аналог: отправить уведомление (локальное, в чат или в Reminders), чтобы не держать окно открытым.

2. **Экспорт / бэкап перед компакцией контекста**  
   Перед тем как контекст сессии будет сжат или сброшен — PreToolUse или специальный hook: записать ключевое состояние (например список созданных тикетов, последний шаг full-flow) в файл в vault (например `00-Inbox/Last_Flow_State.md` или `03-Tasks/linear_sync.json` уже обновлён скриптом).

3. **Загрузка контекста в начале сессии**  
   SessionStart: подставить Quarter Goals, Week Priorities, Pillars, срочные задачи из Tasks.md и т.д., чтобы не запрашивать их вручную.

4. **После сохранения встречи**  
   PostToolUse при записи файла в `00-Inbox/Meetings/`: предложить или автоматически запустить обработку (process-meetings, извлечение задач, обновление person pages) — если это поддерживается в Claude Code.

5. **Перед отправкой тяжёлой команды**  
   PreToolUse перед запуском долгих скриптов (full-flow, массовый экспорт): краткое напоминание о том, что процесс займёт время и не нужно повторять вызов.

**Где настраивать:** в конфигурации Claude Code (не в репозитории Dex). Документация: [code.claude.com/docs/en/hooks](https://code.claude.com/docs/en/hooks). В репо Dex описание и рекомендации — этот файл и скилл `/hooks-recommend`.
