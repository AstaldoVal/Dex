# Поля для автозаполнения ATS-форм (профиль кандидата)

Резюме и Cover Letter не включены — загружаются вручную.  
Ниже список полей, собранных со всех задокументированных форм (Ashby, Greenhouse, Okta, Teamtailor, HiBob). Заполни значения в колонке **Твоё значение** — по ним экстеншн будет подставлять данные в поля при открытии формы.

**Как маппинг работает:** в колонке «Лейблы на формах» перечислены варианты подписей полей в разных ATS. Экстеншн при открытии формы ищет по странице эти подписи (или по id/name инпута) и подставляет значение из «Твоё значение».

## Чекбоксы согласий

Обычно не автозаполняем: пользователь сам ставит галочку после прочтения. При желании можно добавить в экстеншн «авто-чек» для согласия с Privacy Policy, если формулировка на форме совпадает.

---

**Итого полей для ответа:** 1–12 обязательно заполнить для автозаполнения; 13–15 — по необходимости (часто No + пусто). После того как заполнишь «Твоё значение» выше, пришли файл или вставь сюда значения — сохраню в профиль и можно будет использовать в экстеншене.
