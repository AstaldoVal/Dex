# Speak report (озвучивание отчётов)

Озвучивание результатов работы через OpenAI TTS API (для русского) или системный TTS macOS (`say`).

## Использование

- **Озвучить файл:** `npm run speak-report -- path/to/file.md`
- **Остановить озвучивание:** `npm run speak-stop` или `Ctrl+C` в терминале
- **После отчёта в чате:** скажи «озвучь» или «прочитай вслух» — я сохраню отчёт в файл и запущу скрипт.
- **Из stdin:** `echo "Текст для озвучки" | node .scripts/speak-report.cjs --stdin`

## Управление процессом

- **Плавающий виджет (Swift):** Если собран виджет (`.scripts/speak-widget/DexSpeakWidget`), при начале воспроизведения появляется небольшое плавающее окно с индикатором и кнопкой «Остановить». Не поп-ап, не перехватывает фокус. Сборка: `npm run speak-widget:build`.
- **Fallback:** Если виджет не собран, показывается компактный диалог (AppleScript).
- **Остановка:** кнопка в виджете, или `npm run speak-stop`, или Ctrl+C в терминале.
- Виджет автоматически закрывается при завершении озвучивания.

## Опции

- `--stdin` — читать текст из stdin.
- `--no-strip` — не упрощать markdown (озвучивать как есть).
- `--voice NAME` — принудительно использовать системный голос (например `Milena`); отключает OpenAI TTS для русского.
- `--say` — принудительно использовать macOS `say` даже для русского (пропускает OpenAI TTS).
- `--openai-voice NAME` — голос OpenAI: `nova` (по умолчанию, похож на Cove), `alloy`, `echo`, `fable`, `onyx`, `shimmer`.

## Автоматическое определение

**Для русского текста:**
- Если `OPENAI_API_KEY` настроен → использует **OpenAI TTS API** с голосом **Nova** (естественный русский без акцента, как Cove в ChatGPT).
- Если ключ не найден → использует macOS `say` с голосом **Milena**.

**Для английского/другого текста:** использует macOS `say` с голосом по умолчанию.

## Настройка OpenAI TTS (для лучшего качества русского)

1. Добавь `OPENAI_API_KEY` в `.env` файл в корне проекта:
   ```
   OPENAI_API_KEY=sk-your-actual-key-here
   ```
   Или установи переменную окружения: `export OPENAI_API_KEY=sk-...`

2. Скрипт автоматически использует OpenAI TTS для русского текста.

3. Если нужно использовать другой голос OpenAI: `--openai-voice alloy` (или echo, fable, onyx, shimmer).

## Требования

- macOS (для fallback на `say`).
- OpenAI API ключ (опционально, для лучшего качества русского).
