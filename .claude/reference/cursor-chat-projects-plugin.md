# Плагин «Cursor Chat Projects» — иерархическая организация чатов

## Цель

Дать возможность организовывать чаты Cursor в иерархии «проекты → чаты» внутри одного workspace, без смены окна Cursor.

## Ограничения Cursor (на текущий момент)

- **Нет API «открыть чат по ID».**
  Расширение при клике по чату в дереве пробует команды (`cursor.openConversation` и др.); если Cursor их не предоставляет, показывается сообщение и ID копируется в буфер — чат нужно найти вручную в панели агентов. Есть [feature request](https://github.com/cursor/cursor/issues/3910) на ссылки на прошлые чаты.
- **История хранится во внутренней SQLite**, не в папке проекта:
  - macOS: `~/Library/Application Support/Cursor/User/globalStorage/state.vscdb`
  - Ключи вроде `workbench.panel.aichat.view.aichat.chatdata`, `cursorDiskKV` с префиксом `bubbleId:`.
- **Формат БД не документирован** и может меняться; доступ к ней со стороны расширений не поддерживается официально.

## Что можно сделать в расширении

1. **Читать список чатов** из `state.vscdb` (как делают [cursor-chat-history-mcp](https://github.com/vltansky/cursor-chat-history-mcp) и [cursor-db-mcp](https://github.com/jbdamask/cursor-db-mcp)) — через SQLite (например, sql.js в расширении или вызов внешнего скрипта).
2. **Хранить иерархию у себя** в workspace: например, `.cursor/chat-projects.json` в корне Dex или в `System/` — проекты и привязка `conversationId` → проект.
3. **Показывать в сайдбаре TreeView**: «Chat Projects» → проект → список чатов (по нашим данным + заголовки из БД, если удаётся их достать).
4. **Команды и взаимодействие:**
   - «Create project» — создать проект (папку в иерархии).
   - «Assign conversation to project» — привязать выбранный чат к проекту (выбор проекта + ввод ID).
   - «Move to project…» — контекстное меню по чату: выбор целевого проекта, чат переносится.
   - «Remove from project» — контекстное меню: убрать чат из текущего проекта.
   - **Drag and drop:** перетаскивание чата на другой проект в дереве — чат перемещается в выбранный проект.

Задача плагина — структурировать чаты по папкам и перемещать их (меню или DnD). По клику на чат в дереве расширение пытается открыть его в Cursor; при отсутствии API — подсказка и копирование ID в буфер.

## Варианты интеграции с Dex

- **Файл иерархии в Dex:** `System/cursor-chat-projects.json` (или `.cursor/chat-projects.json` в корне), чтобы конфиг жил в vault и бэкапился вместе с ним.
- **Синхронизация имён проектов с 04-Projects:** опционально — при создании проекта в плагине предлагать создать папку в `04-Projects/` или привязать к существующей (только имена/пути, без автоматического создания файлов в Dex).

## Стек и риски

- **Расширение:** VS Code Extension API (Cursor их поддерживает). TreeView, QuickPick, команды, чтение файлов.
- **SQLite:** в расширении проще всего использовать `sql.js` (WASM), чтобы не тянуть нативные модули; либо запускать небольшой Node-скрипт, который читает `state.vscdb` и возвращает JSON (тогда зависимость от Node и пути к БД).
- **Риск:** смена формата/ключей в `state.vscdb` может сломать чтение; придерживаться минимального набора полей (id, заголовок/дата по возможности) и обрабатывать ошибки парсинга.

## Итог

Плагин **реализован** в `tools/cursor-chat-projects/`: иерархия «проекты → чаты», перемещение через контекстное меню («Move to project…», «Remove from project») и drag-and-drop. Конфиг — `.cursor/chat-projects.json` в корне workspace (в Dex хранится в vault).
