# Индекс скиллов продукт-менеджмента в Dex

Единая навигация по всем PM-скиллам: Dex-нативные, deanpeters/Product-Manager-Skills, product-on-purpose/pm-skills, pmprompt/claude-plugin-product-management и BMAD (aj-geddes/claude-code-bmad-skills).

**В этом vault:** все перечисленные ниже PM-скиллы установлены и активны (в т.ч. customer-intel, roadmap, feature-decision из бывшего _available). Выбор скилла — по задаче и категории.

---

## Как пользоваться

- **По задаче:** выбери категорию ниже и скилл под задачу (один артефакт → Component, нужен совет по методу → Interactive, полный процесс → Workflow).
- **По источнику:** раздел 4 — происхождение скилла (Dex, deanpeters, pop, pmprompt, BMAD).
- **Вызов:** `/имя-скилла`, например `/prioritization-advisor`, `/product-brief`, `/customer-intel`.
- **Список категорий одной командой:** `/pm-skills` — выведет все категории и подсказку по индексу.

## 2. По типу скилла (время и способ работы)

- **Component** — Один артефакт или шаблон, 10–30 мин. Примеры: user-story, positioning-statement, jobs-to-be-done.
- **Interactive** — Вопросы → рекомендации → выполнение, 30–90 мин. Примеры: prioritization-advisor, discovery-interview-prep, tam-sam-som-calculator.
- **Workflow** — Многошаговый процесс на дни/недели. Примеры: discovery-process, prd-development, roadmap-planning, product-strategy-session.

## 3. Структура по папкам (универсальный обзор)

Все PM-скиллы объединены в одной папке с указанием источников; единая точка входа — `/pm-skills` и этот файл.

- **Единая папка PM-скиллов** — `.claude/skills/pm/`. Внутри подпапки по источнику: `pm/dex/`, `pm/deanpeters/`, `pm/pop/`, `pm/pmprompt/`, `pm/alirezarezvani/`, `pm/ralph/`. В каждой — скиллы по имени (например `pm/dex/product-brief`, `pm/deanpeters/discovery-process`). Вызов: `/имя-скилла` (как и раньше). Атрибуция и обновление из репозиториев: `.claude/skills/pm/README.md` и `.claude/skills/pm/SOURCES.md`.
- **BMAD** — отдельный модуль в `.claude/skills/bmad/` с подпапками `core/`, `bmm/`, `bmb/`, `cis/`. Вызов через команды: `/workflow-init`, `/prd`, `/tech-spec`, `/workflow-status`. Использует `.claude/commands/bmad/` и `.claude/config/bmad/`. **Не перемещать** BMAD в pm/ — структура обязательна для работы.

**Обновление из исходных репозиториев:** скрипт в той же папке — из корня vault выполнить `./.claude/skills/pm/update.sh` (подтягивает все репо и копирует скиллы в `pm/<источник>/`).

**Почему в списке скиллов нет одной строки «B-MAD»?** BMAD — это 9 отдельных скиллов в `.claude/skills/bmad/` (bmad-master, architect, pm, scrum-master, developer, builder, ux-designer, analyst, creative-intelligence). В Cursor/IDE они отображаются по имени папки или по `name` из SKILL.md (например, «BMad Master», «architect», «pm»). Основной способ использования BMAD — **команды:** `/workflow-init`, `/prd`, `/tech-spec`, `/workflow-status`. См. `.claude/skills/PM_SKILLS_BMAD_README.md`.

## 3.1. Дубликаты и перекрытия

Одна и та же задача или фреймворк может быть покрыт несколькими скиллами из разных источников. Ниже — явные пары/тройки; можно выбрать один источник или пользоваться разными под контекст.

- **JTBD** — jobs-to-be-done (deanpeters), define-jtbd-canvas (pop), pmprompt-jobs-to-be-done (pmprompt). Рекомендация: три варианта одного фреймворка; для быстрого артефакта — deanpeters или pmprompt; в рамках Triple Diamond — define-jtbd-canvas.
- **OST (Opportunity Solution Tree)** — opportunity-solution-tree (deanpeters), define-opportunity-tree (pop), pmprompt-opportunity-solution-trees (pmprompt). Рекомендация: interactive — deanpeters или pmprompt; внутри pop — define-opportunity-tree.
- **Конкурентный анализ** — discover-competitive-analysis (pop), pmprompt-competitive-analysis-framework (pmprompt). pop — компонент Triple Diamond; pmprompt — отдельный фрейм с позиционированием.
- **Приоритизация фич** — prioritization (Dex), prioritization-advisor (deanpeters), pmprompt-feature-prioritization-assistant (pmprompt). Dex — общий выбор метода (RICE и др.); pmprompt — фокус на RICE; advisor — только совет, без расчёта.
- **PRD / требования** — product-brief (Dex), deliver-prd (pop), prd-development (deanpeters), pmprompt-prd-writer (pmprompt), BMAD PM (/prd, /tech-spec). Пять способов: Dex — воркфлоу; pop/deanpeters/pmprompt — компонент или workflow; BMAD — по уровню проекта (tech-spec vs PRD), в связке с product-brief и architecture.
- **Working Backwards** — press-release (deanpeters), pmprompt-working-backwards (pmprompt). deanpeters — компонент пресс-релиз; pmprompt — полный workflow.
- **Синтез обратной связи** — customer-intel (Dex), discover-interview-synthesis (pop), pmprompt-user-feedback-synthesizer (pmprompt). customer-intel — по встречам/персонам Dex; pop — интервью; pmprompt — общий синтез по паттернам.

Итого: **полных дубликатов по имени нет** (все скиллы имеют уникальные имена). Есть **смысловые перекрытия** по JTBD, OST, PRD, приоритизации, Working Backwards, синтезу фидбека, A/B и release notes — при выборе можно ориентироваться на источник (Dex/pop/deanpeters/pmprompt) и тип (Component vs Workflow).
