## Purpose

Один раз в день собрать **субъективные метрики** и **контекст тренировок**, которые Watch не объясняет (RPE, «как пошло», стресс, кофеин, алкоголь, экран). Результат пишется в `05-Areas/Physical/logs/{date}.json` и `.md`, поле `readiness_score` считается в **`.scripts/physical/physical-readiness.cjs`**.

## Режим чата: один вопрос за раз (обязательно)

1. **Один вопрос на одно сообщение ассистента.** Не выводить список будущих вопросов, не давать «заполни всё сразу», не показывать вопрос N+1, пока пользователь не ответил на вопрос N.
2. **К каждому вопросу добавляй примеры ответов** (1–3 строки): допустимый формат, цифры, слова-заглушки. Примеры должны быть конкретными (например `7`, `no`, `neck 2, legs 1`).
3. **После ответа пользователя** кратко зафиксируй значение в уме/черновике и задай **следующий** вопрос по порядку ниже.
4. **Пропуск:** если поле опционально и пользователь пишет `—`, `skip`, `пропуск`, используй пустое значение или значение по умолчанию из существующего лога (если есть), как в **`.scripts/physical/daily-checkin.cjs`**.
5. **Старт сессии:** при первом вызове `/physical-daily-checkin` прочитай `05-Areas/Physical/logs/{сегодня}.json` (если есть), опционально выполни `npm run physical:health-sync` для merge с Health, затем начни с **вопроса 1** (или уточни дату, если нужен другой день).
6. **Финал:** когда все нужные вопросы пройдены, собери JSON, **смержи** с существующим логом (не затирать `steps`, `hrv`, `resting_hr` и объективные поля из Health), пересчитай `readiness_score` через `calculateReadiness`, запиши файлы, предложи **`/physical-check-custom`** для рекомендации дня.

## Два режима (терминал без изменений)

1. **Чат:** только последовательность «один вопрос → один ответ», как выше.
2. **Терминал:** `npm run physical` или `npm run physical:checkin` / `npm run physical:checkin:short` (интерактивный CLI).

## Полный опросник: порядок и примеры (синхрон с `daily-checkin.cjs` runFull)

Задавай вопросы **строго в этом порядке**. Поле JSON указано для финальной сборки.

### Сон и энергия

1. **Часы сна прошлой ночью** (`sleep_hours`, 0–24). Примеры: `6.5`, `8`, `5`.
2. **Качество сна** (`sleep_quality`, 1–10). Примеры: `4`, `7`, `9`.
3. **Энергия сейчас** (`energy`, 1–10). Примеры: `3`, `6`, `8`.
4. **Стресс / напряжённость** (`stress`, 1=низко, 10=высоко). Примеры: `2`, `5`, `8`.
5. **Настроение** (`mood`, 1–10). Примеры: `4`, `6`, `9`.
6. **Психическая усталость / перегруз** (`mental_fatigue`, 1–10). Примеры: `3`, `6`, `9`.

### Тело

7. **Зоны болезненности мышц** (`muscle_soreness`). Формат: `none` или зоны с силой 1–3: `зона интенсивность` через запятую. Примеры: `none`, `back 2, legs 1`, `quads 3`.
8. **Зоны напряжения от сидения** (`posture_tension`). Примеры: `none`, `neck, shoulders`, `lower_back`.
9. **Качество питания сегодня** (`nutrition`, 1–10). Примеры: `5`, `7`.

### Тренировки

10. **Сколько было структурированных тренировок сегодня** (0–3) — дальше столько же блоков из четырёх вопросов. Примеры: `0`, `1`, `2`.

Если **0** — перейди к вопросу про алкоголь (номер 11 в этом списке).

Если **≥1**, для тренировки **k** = 1…N по очереди:

- **10kа.** Тип (`training_sessions[k].type`). Примеры: `walk`, `run`, `strength`, `yoga`, `intervals`, `other`.
- **10kб.** Длительность в минутах (`duration_min`). Примеры: `25`, `45`, `60`.
- **10кв.** RPE (`rpe_1_10`, 1–10). Примеры: `3`, `6`, `8`.
- **10кг.** Как прошло (`felt`). Примеры: `easy`, `ok`, `hard`, `too much`.

### Привычки

11. **Алкоголь сегодня** (`alcohol`). Примеры: `no`, `yes 2`, `yes 1 glass`, `yes 2 beers`. Если не `no`, следующим сообщением (отдельный вопрос) спроси **время последнего напитка** (`alcohol.time`, ЧЧ:ММ или `skip`). Примеры: `22:30`, `skip`.
12. **Кофеин: что и сколько** (`caffeine.description`). Примеры: `2 espressos`, `200 mg`, `none`, `skip`.
13. **Время последнего кофеина** (`caffeine.last_time`). Примеры: `14:00`, `skip`.
14. **Время последнего приёма пищи** (`last_meal_time`). Примеры: `21:30`, `20:00`.
15. **Минуты экрана в последний час перед сном** (`screen_before_bed_min`, 0–120). Примеры: `0`, `30`, `60`.
16. **Когда убрал телефон / цель** (`phone_away_time`). Примеры: `23:00`, `22:45`, `skip`.

### Гидратация и здоровье

17. **Вода примерно в литрах** (`hydration_liters`). Примеры: `1.5`, `2`, `skip`.
18. **Соль / обезвоживание** (`salt_heavy_or_dehydrated`). Примеры: `none`, `salty`, `low_water`.
19. **Чувствуешь ли болезнь** (`illness`). Примеры: `no`, `лёгкая простуда`, `боль в горле` (как в CLI: один ответ с описанием или `no`). Если ответ не `no` и не пустой, следующим сообщением: **температура °C**, если знаешь (`37.2`, `skip`, пусто). Затем отдельным сообщением: **лекарства** (`ибупрофен`, `none`, пусто). Симптомы берутся из ответа на 19.
20. **Боль / травма** (`pain_injury`). Примеры: `none`, `knee:4`, `lower_back:6`.

### Опциональные виталии и заметки

21. **Вес кг** (`weight_kg`, опционально). Примеры: `82.4`, `skip`.
22. **Процент жира** (`body_fat_pct`, опционально). Примеры: `18`, `skip`.
23. **Давление** (`blood_pressure`, опционально). Примеры: `120/80`, `skip`.
24. **Заметка по анализам** (`labs_note`, квартал). Примеры: `vit D ok Feb`, `skip`.
25. **Свободные заметки** (`notes`). Примеры: `тяжёлый рабочий день`, `—`.

После ответа на последний вопрос: **merge**, `readiness_score`, запись файлов, краткий итог с цифрой готовности.

## Короткий режим (чат)

Если пользователь просит короткий check-in: только поля из `runShort` в **`.scripts/physical/daily-checkin.cjs`**, тот же принцип **один вопрос за раз с примерами**: сон часы, качество сна, энергия, мышцы, напряжение, питание, заметки (порядок как в `runShort`).

## Как мержить с Apple Health

- Если файл `05-Areas/Physical/logs/{date}.json` уже есть после синка Health, новые субъективные поля **дописываются**; объективные метрики из Health не затирать смыслово (см. **`apple-health-sync.cjs`** `mergeIntoLog`).
- Оценка сна **1–10** для формулы: при синке сначала берётся явный **скор** из экспорта (если есть), иначе **эвристика по стадиям Watch** (`totalSleep`, deep, REM, awake) из строки `sleep_analysis`; иначе значение из опросника. Поле **`qty`** у метрики **`time_in_daylight`** — минуты на свету, **не** качество сна. В логе смотри **`sleep_quality_source`**: `checkin` | `derived_stages` | `health_export`.
- Патч: `echo '<json>' | node .scripts/physical/merge-physical-checkin.cjs --date YYYY-MM-DD` или запись через инструменты.

## Apple Watch (контекст)

- Watch даёт тип и длительность; RPE и «как пошло» — только в опроснике.
- Тип тренировки в ответе можно согласовать с тем, что выбрано в Workout на часах.

## Весы Xiaomi / Xiaomi Home

- **Xiaomi Home** может писать в Apple Health: вес, % жира, BMI, lean body mass (если включено в Здоровье).
- Цепочка для Dex: Health → **Health Auto Export** (JSON в iCloud) → **`apple-health-sync`** → поля `weight_kg`, `body_fat_pct`, при наличии в экспорте `bmi`, `lean_body_mass_kg`.
- Весы должны быть подключены к Xiaomi Home, иначе в Health не попадёт; если офлайн — вес в опроснике (вопросы 21–22) или вручную в Здоровье.
- Zepp Life / Mi Fit — альтернативный путь для части устройств; для Dex важен только факт записи в Health.

## Связанные команды

- `/physical-check-custom` — рекомендация по готовому логу
- `npm run physical:health-sync` — обновить метрики из экспорта Health
- `npm run physical:checkin` — полный терминальный опросник
