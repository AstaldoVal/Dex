# Teal: удаление копий резюме

**Команда:** `/teal-cleanup-copies`

Удаление **копий и дубликатов** резюме в Teal с **обязательным сохранением эталонных** резюме.

- **Копии по названию:** резюме, в названии которых есть « copy» или « copy 2», « copy 3» и т.п. (как Teal называет дубликаты). Удаляются все такие, кроме защищённых.
- **Дубликаты по одинаковому названию:** если в списке несколько резюме с **одним и тем же** названием (без « copy»), считаются дубликатами. Из них **оставляется одно** — то, у которого **нет привязки к вакансии** в Job Matcher (в строке нет ссылки на job-tracker). Остальные с тем же названием удаляются. Если у всех есть привязка или у всех нет — оставляется первое, остальные удаляются.
- **Эталоны:** резюме, чьи ID перечислены в списке защищённых, **никогда не удаляются**.

## Когда вызывать

- Пользователь просит удалить копии резюме в Teal, почистить список от дубликатов.
- После массового создания резюме через `/teal-resume` или `/teal-resume-batch`, когда нужно оставить только эталоны и удалить лишние копии.

## Что делать

1. При необходимости: если другой Teal-скрипт уже запущен (Chrome занят), скрипт попробует профили **Profile 1**, **Profile 2**. Вход в Teal по **TEAL_EMAIL** и **TEAL_PASSWORD** из `.env`.
2. Из корня репо выполнить:
   ```bash
   npm run job-search:teal-cleanup-copies
   ```
3. Скрипт откроет Chrome, перейдёт на страницу списка резюме, найдёт все резюме с названием, содержащим « copy» (в т.ч. « copy 2», « copy 3»), кроме защищённых по ID, и для каждого откроет меню (три точки) → Delete → при необходимости подтвердит удаление.
4. Кратко сообщить пользователю результат: сколько копий удалено (или что копий не найдено).

## Защищённые резюме (эталоны)

- По умолчанию защищён один ID (эталонное резюме). Список задаётся в **.env**:
  - **TEAL_PROTECTED_RESUME_IDS** — через запятую UUID резюме, которые нельзя удалять. Пример:
    ```env
    TEAL_PROTECTED_RESUME_IDS=c0ad3ea2-8d9e-4e84-8b60-eab3172de3d9,другой-uuid-эталона
    ```
- Если переменная не задана, используется один ID по умолчанию (как раньше).
- Резюме с этими ID не удаляются независимо от названия.

## Требования

- Playwright установлен (`npm install playwright`).
- В `.env` заданы **TEAL_EMAIL** и **TEAL_PASSWORD** для авто-входа при редиректе на sign-in (в т.ч. при запуске в Profile 1/2).

Скрипт: `.scripts/job-search/teal-cleanup-resume-copies.cjs`.

**Лог в файл:** весь вывод пишется также в `00-Inbox/Job_Search/teal/teal-cleanup-copies.log`. Прогресс в реальном времени:
```bash
tail -f 00-Inbox/Job_Search/teal/teal-cleanup-copies.log
```

## Если сломалось (смена вёрстки Teal)

Если скрипт перестал находить строки резюме, кнопку меню или пункт Delete:

1. Запустить скилл **`/teal-ui-learn-custom`** и при необходимости `npm run job-search:teal-ui-learn`.
2. Изучить сохранённый при ошибке `00-Inbox/Job_Search/teal/teal-cleanup-debug.html` и обновить селекторы в `.scripts/job-search/teal-cleanup-resume-copies.cjs` (контейнер строки, кнопка меню `button[aria-label="Resume Menu"]`, пункт Delete в меню, кнопка подтверждения).
3. При обновлении карты в `.claude/reference/teal-ui-map.md` добавить блоки для списка резюме и меню.
