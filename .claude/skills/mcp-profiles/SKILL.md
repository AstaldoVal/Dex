# MCP-профили по сценариям

Скилл подсказывает, **какие MCP имеет смысл включить** для текущего сценария работы (PM, job search, meetings, writing и т.д.). Конфигурация MCP меняется пользователем вручную (Cursor/Claude Code); в репо Dex готовых «профилей» с автопереключением нет — только рекомендации.

## Purpose

Набор MCP в Dex задаётся глобально. Для разных задач удобны разные наборы: для PM — Linear, Figma; для job search — career, Gmail; для встреч — Calendar, Granola, Work. Скилл по названию сценария возвращает рекомендуемый список MCP и кратко зачем каждый.

## When to Use

- Пользователь спрашивает: «какие MCP включить для PM?», «что нужно для job search?», «профиль для встреч».
- Обсуждается настройка Cursor/Claude Code под конкретный тип задач.
- В контексте dex-level-up или onboarding — подсказать оптимальный набор под сценарий.

## Сценарии и рекомендуемые MCP

Использовать таблицу или список. Имена серверов — как в конфиге (например `user-linear`, `user-career-mcp`). Если сервер опционален — пометить.

| Сценарий | Рекомендуемые MCP | Зачем |
|----------|-------------------|--------|
| **PM flow** (продукт, тикеты, дизайн) | Linear, Figma (если есть), Work (задачи Dex), опционально Notion, Nano Banana (диаграммы) | Тикеты в Linear, макеты в Figma, задачи в Dex, визуалы по PRD/journey |
| **Job search** (вакансии, отклики, резюме) | Career MCP, Work, опционально Gmail, Resume MCP | Статистика, задачи по откликам, резюме и Teal-флоу |
| **Meetings / daily** (встречи, план дня) | Calendar, Granola, Work, Reminders | Календарь, заметки встреч, задачи, напоминания |
| **Writing / content** (документы, посты) | Work, опционально Notion | Задачи и контент без лишних dev/design MCP |
| **Full stack** (макс. контекст) | Все нужные под текущий проект: Linear, Figma, Work, Calendar, и т.д. | Когда важна доступность всех инструментов |

Детали по каждому MCP — в `.claude/reference/mcp-servers.md`. Общая идея профилей и ограничения — в `.claude/reference/claude-github-app-and-mcp-profiles.md` (раздел «Профили MCP по сценариям»).

## Process

1. Уточнить сценарий: PM, job search, meetings, writing, или «всё под проект X».
2. Вернуть рекомендуемый список MCP для этого сценария (и кратко зачем).
3. Напомнить, что включение/выключение делается в настройках MCP (Cursor/Claude Code); при необходимости дать ссылку на `mcp-servers.md` или `cursor-sync-mcp.py`.

## Output

- Список MCP для сценария с краткими обоснованиями.
- Упоминание, что это рекомендация; фактическая конфигурация — вручную.

## Notes

- Не обещать автоматическое переключение профилей: в репо такого механизма нет.
- Если у пользователя нет части серверов (например Figma) — рекомендовать только те, что у него могут быть; не навязывать недоступные.
