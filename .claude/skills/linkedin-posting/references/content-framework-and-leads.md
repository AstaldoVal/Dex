# LinkedIn: контент-фреймворк и привлечение лидов

**Источник:** YouTube, видео «Step-by-step process to get more clients on LinkedIn using content» (Slm6Ek465ow).  
**Дата добавления в референсы:** 2026-02-16.

---

## Best practices (из видео)

### 1. Выбор темы и поиск идей

- Выписать одну простую тему для контента (success, remote work, lead generation, entrepreneurship, deep work и т.д.).
- Внутри темы выделить три конкретных подпункта, о которых хочешь говорить.
- Не придумывать с нуля: искать **уже зашедший контент** по ключевому слову в инструментах:
  - **Tapo** — для LinkedIn: поиск по теме/ключевому слову, сотни готовых идей; можно фильтровать по цели поста (educate / inspire / entertain).
  - **Tweet Hunter** (Chrome-расширение) — для Twitter, но авторы используют и для LinkedIn из‑за объёма контента; поиск по ключевому слову, разбор постов любимых авторов.
- Сохранять понравившиеся посты в swipe-файл или скриншоты для вдохновения.

### 2. Цель поста перед написанием

У каждого поста должна быть одна из трёх целей:

- **Educate** — научить (how to, X steps, here's how).
- **Inspire** — вдохновить.
- **Entertain** — развлечь.

Определять цель до написания и отбирать референсы под неё, чтобы не «проваливаться в кроличью нору» без фокуса.

### 3. Эмуляция, а не копирование

- Использовать **структуру и ритм (cadence)** понравившегося поста: как начинается, сколько строк, есть ли буллеты, как заканчивается (CTA, вопрос).
- Заполнять эту структуру **своими идеями и опытом**.
- Цитата из видео: «If you steal from one person you're a thief, if you steal from everyone that's research.»

### 4. Превращение вовлечённости в лиды (one true fan)

- Не «post and ghost»: лиды уже в комментариях, их нужно «согревать».
- После каждого поста **смотреть, кто комментирует** — искать там ICP (Ideal Client Persona).
- Заголовок профиля обычно явно говорит, кто человек и чем занимается.
- Действия:
  - Написать персональный **connection request**, если ещё не в контактах.
  - Ответить в комментариях — персонально, по-человечески (среди автоматизаций и AI «just be human»).
- Простой скрипт для ответа: поблагодарить за комментарий + мягкий вопрос по теме поста. Пример: «Hey [Name], thank you for commenting, that was kind. How's LinkedIn going for you this [year]?»
- Если человек отвечает — интерес есть (к офферу или к тебе); на LinkedIn люди чаще всего в B2B-режиме, цель — продажи и связи.

### 5. Фреймворк поста SLAY

Структура из четырёх блоков:

1. **S — Story**  
   Начать с истории (крючок, личный опыт).

2. **L — Lesson**  
   Кратко: почему это важно для читателя, какой урок/контекст.

3. **A — Actionable advice**  
   Конкретная польза: шаги, советы, чтобы читатель получил ценность, а не только «воду».

4. **Y — You / PS**  
   Завершение с «ты»-элементом: вопрос читателю, платитуда или фраза, которая даёт ощущение «меня услышали».

Почему это работает (по видео): в одном посте даётся **inspiration** в начале, **education** в середине, **entertainment** по ходу.

## Чек-лист перед публикацией

- В начале поста есть цепляющий заголовок (одна строка, не общее место).
- Тема и три подпункта определены.
- Цель поста выбрана (educate / inspire / entertain).
- Структура и ритм взяты из референса, контент — свой.
- Пост соответствует SLAY (или осознанно отклоняется с причиной).
- В конце поста добавлены релевантные хэштеги (3–7 тегов по теме).
- План работы с комментариями: смотреть на ICP и отвечать/добавлять в контакты.
- При генерации поста с нуля: также сгенерирована картинка через Nano Banana (nanobanana_generate).
