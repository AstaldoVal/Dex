# Мероприятия для Мии — детские ивенты 4+

**Команда:** `/mia-events` или запросы вида «ивенты для Мии», «что можно с Мией на [дата]», «детские мероприятия на воскресенье».

**Цель:** Выдать нумерованный список детских мероприятий на указанную дату (по умолчанию — сегодня) в регионе Grande Lisboa (включая левый берег/Алмада), Оэйраш, Кашкайш, Синтра. Только события, подходящие для возраста **4+ лет**. Формат: чёткая иерархия (заголовок → описание и ссылки с отступом).

**Зона и поездки:** Лиссабон (в т.ч. Алмада — левый берег), Оэйраш, Кашкайш, Синтра, окрестности. Радиус поездки: 30 мин – 1 ч на машине.

**Контекст: Мия**
- День рождения: **07.05.2021**. По этой дате считать возраст на дату ивентов: фильтр «4+» подходит с мая 2025 года; при запросе на конкретную дату проверять, что возраст Мии на ту дату не меньше указанного порога.
- **Предпочтения:** качели, батуты, танцы, бассейн, рисование, песок на пляже — желательно с другими детьми; музыка ок; полдня нормально; коляска не нужна. Подробнее: `05-Areas/People/External/Mia.md`.
- **День рождения (07.05):** напоминать заранее (уже с начала года / за 2–3 месяца до даты): бюджет ограничен, планировать праздник и расходы заранее. При `/daily-plan` и в период фев–май по возможности включать напоминание: «День рождения Мии 07.05 — запланировать праздник? Бюджет ограничен, имеет смысл думать заранее».

## Источники ивентов

### Веб-афиши и муниципальные сайты

- **Time Out Lisboa** (timeout.pt/lisboa/pt/miudos) — ежемесячная подборка «Coisas para fazer com crianças»: театр, выставки, мастер-классы, возрастные рекомендации.
- **Lisboa Events** (lisboa.events) — платная платформа с календарём событий 0–12 лет по Лиссабону, Кашкайшу, Оэйрашу, Синтре и др.; в превью доступны анонсы на 2 недели вперёд.
- **Cascais 360º** (360.cascais.pt/pt/agenda/infantil) — официальная детская повестка муниципалитета Кашкайш.
- **Oeiras** (oeiras.pt, agendanatureza.oeiras.pt) — мероприятия и «Agenda da Natureza» (офины, природа, экскурсии).
- **Pumpkin.pt** — семейная повестка и фестивали для детей.

### Telegram-каналы

- **Arte Oeiras** (t.me/artoeiras) — студия Art Oeiras: арт-занятия, лагеря, рисование 4–6 и 7–12 лет, гитара, шахматы, Оэйраш.
- **Liberty events** (t.me/libertyevents) — вечера в Liberty café (Лиссабон, Parede), в т.ч. детские спектакли.
- **Афиша Лиссабон** (t.me/AfishaLissabon) — концерты, детские события, экскурсии, фестивали (на русском).
- **Mama Oeiras** (t.me/mamaoeiras) — чат: Оэйраш/Кашкайш, куда сходить с детьми.
- **Мама на пляже** (t.me/mamapt) — анонсы мероприятий в Оэйраш и окрестностях.
- **Івенти Portugal** (t.me/ivents_portugal) — события для украинцев, Великий Лиссабон.
- **Minuto Português** (t.me/minutoportugues) — превью может не загружаться (таймаут).
- **Афиша Lisboa** (t.me/AfishaLisboa) — день и ночь в Лиссабоне, концерты, выставки.
- **Events PT** (t.me/eventspt) — ивенты для украинцев в Португалии.
- **Как в Лиссабоне** (t.me/kakvlx) — жизнь в городе, не календарь событий.

**Как подтягивать Telegram:** через публичное превью в браузере — `mcp_web_fetch` по URL вида `https://t.me/s/<username>`. В превью видны последние посты; старые или скрытые посты недоступны без API/бота.

## Процесс

1. **Дата.** Если пользователь не указал дату — считать «сегодня» (текущая дата из контекста).
2. **Поиск.** Web search по запросу вида «eventos crianças [дата] Lisboa Oeiras Cascais» и «agenda infantil [дата]»; при необходимости — «children events [date] Lisbon».
3. **Муниципальные и афиши.** По необходимости: fetch 360.cascais.pt (infantil), timeout.pt (miudos), lisboa.events (превью), oeiras.pt.
4. **Telegram.** Fetch превью каналов из списка выше: `https://t.me/s/artoeiras`, `https://t.me/s/libertyevents`, `https://t.me/s/AfishaLissabon`, `https://t.me/s/mamapt`, и остальных по необходимости.
5. **Фильтр.** Оставлять только события, подходящие для возраста **4+ лет**. Исключать явно 6+ или «для подростков», если пользователь не просит иное.
6. **Формат вывода** (обязательно):
   - Заголовок раздела: «Детские события на [дата] (4+ лет)».
   - Каждый ивент — нумерованный заголовок уровня ### (1., 2., 3., …).
   - Под каждым заголовком с отступом:
     - время, место, цена (если есть);
     - краткое описание (1–3 предложения);
     - возрастная метка 4+;
     - маркированный список ссылок (подробнее, билеты, источник).
   - Описание и ссылки не смещать влево относительно названия ивента.

## Как можно улучшить скилл

1. **Автоматизация сбора по дате.** Скрипт или MCP-инструмент, который по заданной дате:
   - дергает поиск и фиксированные URL афиш;
   - сохраняет результат в файл, например `00-Inbox/Mia_Events/YYYY-MM-DD.md`, чтобы не дублировать запросы в один день.

2. **Telegram API / бот.** Чтобы стабильно «вытягивать» ивенты из каналов, а не только из публичного превью: бот с доступом к Telegram или парсер через Telegram API (история постов, фильтр по ключевым словам «дети», «crianças», дата). Тогда можно добавлять в скилл шаг «запросить посты за последние N дней из каналов X, Y, Z».

3. **Параметры в команде.** Поддержка аргументов: дата (по умолчанию сегодня), возраст (по умолчанию 4+), зона (по умолчанию Lisboa + Oeiras + Cascais). Например: `/mia-events 2026-02-22` или «ивенты для Мии на субботу 6+».

4. **Единый конфиг источников.** Вынести список URL и каналов Telegram в отдельный файл (например `mia-events/sources.md` или YAML), чтобы добавлять/удалять источники без правки SKILL.md.

5. **Напоминание «проверить каналы».** В daily-plan или отдельном напоминании: раз в день или в начале выходных предлагать «Проверить ивенты для Мии на [дата]?» со ссылками на t.me/s/... для быстрого ручного просмотра, если автоматический сбор по Telegram ограничен.

6. **Интеграция с календарём.** После одобрения пользователем — добавлять выбранные ивенты в календарь (через Calendar MCP или экспорт в .ics), чтобы дата и время не терялись.
