Озвучить текст или файл через TTS. Для русского использует OpenAI TTS (голос Nova), для других языков — macOS say.

## Usage

- `/speak` — озвучить текущий открытый файл или последний упомянутый файл
- `/speak <file>` — озвучить указанный файл
- `/speak --stdin` — озвучить текст из stdin (можно передать через pipe)
- **Выделение текста:** Выдели текст в редакторе и нажми `Cmd+Shift+S` — текст будет озвучен автоматически

## Options

- `--stdin` — читать текст из stdin
- `--no-strip` — не упрощать markdown
- `--voice NAME` — принудительно использовать системный голос (например `Milena`)
- `--say` — принудительно использовать macOS `say` даже для русского
- `--openai-voice NAME` — голос OpenAI: `nova` (по умолчанию), `alloy`, `echo`, `fable`, `onyx`, `shimmer`

## Behavior

1. **Если файл не указан:**
   - Проверь открытые файлы в IDE (из контекста)
   - Если есть открытый файл — используй его
   - Если нет — спроси пользователя, что озвучить

2. **Запуск озвучки:**
   - Используй `npm run speak-report -- <file>` для файла
   - Или `npm run speak-report -- --stdin` для stdin
   - Запускай в фоне (не жди завершения)

3. **Управление:**
   - При начале воспроизведения появляется плавающий виджет (Swift) с кнопками паузы и остановки
   - Пауза сохраняет позицию — при возобновлении продолжается с того же места
   - Остановка: кнопка в виджете, `npm run speak-stop`, или Ctrl+C

4. **Автоматическое определение:**
   - Для русского текста: OpenAI TTS (Nova) если `OPENAI_API_KEY` настроен, иначе macOS say (Milena)
   - Для других языков: macOS say

## Examples

```
/speak
/speak 00-Inbox/Job_Search/digests/linkedin-jobs-2026-02-09.md
echo "Текст для озвучки" | npm run speak-report -- --stdin
```

## Выделение текста (плавающая кнопка)

**Способ 1: Расширение с плавающей кнопкой (рекомендуется)**

Установи расширение для плавающей кнопки при выделении текста:

1. Открой Cursor/VSCode
2. Нажми `Cmd+Shift+P` (или `Ctrl+Shift+P`)
3. Введи: `Extensions: Install Extension from Location...`
4. Выбери папку: `.vscode/extensions/dex-speak-button`
5. Перезапусти Cursor/VSCode

**Использование:**
1. Выдели текст в редакторе
2. Наведи курсор на выделенный текст
3. Появится подсказка с кнопкой "🔊 Озвучить выделенный текст"
4. Нажми на ссылку в подсказке
5. Текст будет озвучен

**Способ 2: Через буфер обмена**
1. Выдели текст и скопируй его (`Cmd+C`)
2. Запусти: `npm run speak-selection`
3. Текст из буфера обмена будет озвучен

## Notes

- Виджет автоматически закрывается при завершении озвучивания
- Процесс работает независимо — можно закрыть чат, озвучка продолжится
- Для остановки используй кнопку в виджете или `npm run speak-stop`
