# Dex: System (система и улучшения Dex)

Тема: **System**. Покажи список скиллов и выполни выбранный.

**Скиллы в этой группе:**

0. **назад** — вернуться к списку тем (Planning, Career, Meetings и т.д.)
1. **dex-level-up** — обнаружить неиспользуемые возможности Dex по твоим паттернам
2. **dex-backlog** — AI-ранжирование идей улучшения Dex
3. **dex-improve** — проработка идеи улучшения в план внедрения
4. **dex-whats-new** — что нового: learnings + обновления Claude
5. **dex-update** — обновить Dex (что нового, подтверждение, без технических шагов)
6. **dex-rollback** — откатить последнее обновление
7. **dex-obsidian-setup** — включить интеграцию с Obsidian и вики-ссылки
8. **dex-demo** — переключить демо-режим
9. **integrate-mcp** — подключить MCP из Smithery.ai или GitHub
10. **create-mcp** — создать новую MCP-интеграцию (мастер)
11. **dex-add-mcp** — добавить MCP с Dex-safe scope (user по умолчанию)
12. **prompt-improver** — превратить размытый промпт в структурированный (Anthropic API)
13. **create-skill** — создать свой скилл (защищён от обновлений Dex, суффикс -custom)
14. **scan-skill-injection** — проверка скиллов на prompt injection и supply-chain
15. **beta-activate** — активировать бета-фичу по коду
16. **beta-status** — список активированных бета-фич

**Твои действия:**

1. Выведи список с номерами и краткими описаниями.
2. Спроси: "Напиши номер или название скилла. 0 — вернуться к списку тем."
3. Когда пользователь ответит: если **0** или **назад** или **меню** — выведи нумерованный список всех 7 тем и попроси выбрать тему. Иначе прочитай `.claude/skills/<skill-name>/SKILL.md` и выполни скилл.

Если пользователь уже указал номер или название: если 0/назад/меню — покажи список тем; иначе выполни скилл.
