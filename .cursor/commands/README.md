# Slash-команды Dex в Cursor

При нажатии **/** в чате Cursor в списке может отображаться только часть команд. В `.cursor/commands/` лежат **короткие точки входа**; полные инструкции — в `.claude/skills/<name>/SKILL.md` и в `.claude/cursor-commands/` (меню `/dex`).

## Команды в этом каталоге

- **dex** — меню всех 7 тем и скиллов по группам.
- **full-flow** — полный поток LinkedIn → Teal (8 шагов); канон: `.claude/skills/full-flow/SKILL.md`.

**Autosuggest в новых чатах:** Cursor надёжнее подхватывает slash из **`.cursor/skills/<имя>/SKILL.md`**, не только из этого каталога. После правок меню или команд: `npm run cursor:sync-slash`, затем **Reload Window**. Полный каталог slash: `.cursor/slash-manifest.json` (82+ пунктов: dex-меню + BMAD + legacy commands).

## Как пользоваться `/dex`

1. Нажми **/** и выбери **dex** (или введи `/dex`).
2. В **ответе модели** появится полный список из **7 тем** (все варианты видны в чате, а не в выпадающем списке):
   - Planning, Career, Meetings, Projects, System, Documents, AI
3. Напиши номер темы (1–7) или название (например `2` или `Career`).
4. Модель покажет скиллы выбранной группы и попросит выбрать скилл. Напиши номер или название скилла — он будет выполнен.

Тематические описания и списки скиллов лежат в `.claude/cursor-commands/` (dex-planning.md, dex-career.md и т.д.). Добавлять новые скиллы нужно в соответствующий файл там и при необходимости в `.claude/skills/`.

## Как пользоваться `/full-flow`

1. Нажми **/** и выбери **full-flow** (или введи `/full-flow`).
2. Пришли ссылку на поиск/вакансию LinkedIn или вставь текст вакансии, когда агент попросит (или сразу в том же сообщении).
3. Агент читает `.claude/skills/full-flow/SKILL.md` и гоняет flow сам.

Полный каталог скиллов: `.claude/skills/README.md` или команда `/dex-level-up`.
