# Ruby Labs Growth Backlog

Local-first hypothesis backlog for Vegas Bonanza (Ruby Labs Growth Manager context).

## Features

- RICE scoring and prioritization
- Drag-and-drop manual reorder
- Primary metric and guardrail mapping
- FTD projection chart
- Browser localStorage persistence

## Dev

```bash
cd apps/ruby-labs-growth-backlog
npm install
npm run dev
```

## Deploy (Vercel)

```bash
npm run build
npx vercel deploy --prod
```
