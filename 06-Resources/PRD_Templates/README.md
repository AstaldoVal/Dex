# PRD Templates Collection

Собраны известные шаблоны Product Requirements Document (PRD) из различных источников. Документы сохранены в оригинальном виде для просмотра структуры и наполнения.

## Список файлов

1. **01_PRDGPT_Template.txt** — prdgpt.com, полная структура
2. **01_PRDGPT_Template_TravelEase_Example.txt** — заполненный пример TravelEase (B2B travel SaaS) по тому же шаблону
3. **02_Aha_PRD_Guide.txt** — aha.io, Product/Release/Epic/Feature requirements (general guide)
4. **02_Aha_Agile_PRD_Template.txt** (.docx, .pptx) — aha.io, Agile PRD: Objective, Background, Features/Stories, UX, Constraints, Open Questions (1 of 3 Aha templates)
5. **02_Aha_PRD_Presentation_Template.txt** (.pptx) — aha.io, PRD Presentation: 19 элементов — для executives/stakeholders (2 of 3 Aha templates)
6. **02_Aha_Release_Requirements_Template.txt** (.xlsx, .pptx) — aha.io, Release Requirements: Name, Target date, Status, Overview, Team, Strategic alignment, Personas, Features, Milestones, Dependencies, Notes — cross-functional release planning (3 of 3 Aha templates)
7. **03_Atlassian_Confluence_Product_Requirements.txt** (.doc) — atlassian.com, Confluence PRD: 5 шагов (basics, Objective + Success metrics, Assumptions + Options, Supporting docs, Open questions + Out of scope)
8. **04_Monday_Com_PRD.txt** — monday.com, 10 компонентов, 6 секций
9. **05_Medium_Design_Bootcamp_PRD.txt** (.docx) — medium.com, Ofri Yehuda "The Only PRD Template You Need", Design Bootcamp
10. **06_Amazon_Working_Backwards_PR_FAQ.txt** (.docx) — pilot.io, Press Release + FAQ (альтернатива PRD)
11. **07_BMAD_PRD_Template.md** — BMAD Method (Dex), полный шаблон с placeholders
12. **08_Alirezarezvani_Product_Manager_Toolkit_PRD.md** — github.com/alirezarezvani/claude-skills, Standard/Epic/One-Page/Feature Brief
13. **09_ChatPRD_Template** — chatprd.ai: `.txt` (6 секций: Background, Objectives, Features, UX, Milestones, Technical); `.md` (вариант из чата: TL;DR, Goals, User Stories, Functional Requirements, User Experience, Narrative, Success Metrics, Technical Considerations, Milestones & Sequencing)
14. **10_Aakash_Gupta_PRD** — aakashg.com: `.txt` (core framework: Problem, Goals, User Stories, Functional Requirements, Acceptance Criteria, Non-Functional); `.md` (ChatPRD variant "Aakash's PRD": 14 секций — Problem, High Level Approach, Narrative, Goals, Metrics, Impact Sizing Model, Non-goals, Solution Alignment, Key Features, Future Considerations, Key Flows, Key Logic, Launch Plan, Key Milestones)
15. **11_Peter_Yang_PRD** — Peter Yang (Roblox): `11_Peter_Yang_Peters_PRD.txt` (7 секций, summary); `11_Peter_Yang_PRD_Template_Full.txt` (полный шаблон из .docx с примерами Pinterest topic selector: Problem, Goals, Requirements, Meeting notes, Launch plan, Appendix)
