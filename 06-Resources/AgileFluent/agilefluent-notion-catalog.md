# Каталог публичных страниц AgileFluent (Notion)

- Дата сбора: 2026-08-04 (UTC).

- Пространство: AgileFluent.
- Telegram проекта (из страницы «Фриланс-платформы»): https://t.me/agilefluent
- Публичных страниц в каталоге: **50**.
- Метод: публичный API Notion + перекрёстная проверка URL из Wayback Machine.
- Ограничение: в каталог попали только страницы с публичным доступом reader/comment. Приватные страницы workspace сюда не входят.

## Как читать каталог

- Разделы сгруппированы по теме, не один в один как сайдбар Notion.
- У каждой страницы: название, ссылка, дата последнего редактирования.
- Есть дубли близких чек-листов и «Топ-9 ошибок» с разными URL — оставляю оба, чтобы не потерять актуальный.
