Закрепи эту заметку. Вечером — короткий лог. Один раз в день — час оркестрации со счётчиком «дорогих» событий.

- Тема обучения на неделю (или «не беру»): …

## Практика недели: час оркестрации

**Не цель:** меньше агентов. **Цель:** меньше утечек и «потерял нить» между проверками.

**Не считать галочкой**

- Дал задачу агенту A → перешёл к агенту B, пока A работает
- Быстрая проверка «готово ли» и возврат к другому агенту

**Считать галочкой (любое из четырёх)**

- [ ] **Утечка** — пока агенты работают, ушёл в Telegram / Instagram / почту / телефон / «прибрать вкладки» не ради ответа агента
- [ ] **Потеря нити** — «кто что делает / что я жду»
- [ ] **Брошенный хендофф** — сменил агента **без** строки состояния (см. правило выше)
- [ ] **Холодный возврат** — разбираю вывод агента после утечки или другой темы **без** 30 сек перечитать свою строку

**Час оркестрации (выбери любой рабочий час)**

- [ ] Час выбран: …
- [ ] В конце часа — **число галочек** (только 4 типа выше): …
- [ ] Топ-1, что сорвало чаще всего: …

## Вечерний лог (5 минут)

**Типовая задача (помодоро)**

- [ ] Был кусок выбранного типа? да / нет
- [ ] Если да — сколько помодоро по 25 мин до «можно отдать»: …

**Решения (одна строка)**

- [ ] Значимых не было **или** принял … / без отката …
- Значимое = откат >30 мин **или** меняет приоритеты на 3+ дня **или** деньги / люди / срок / обещание

**Обучение**

- [ ] Тему не вёл **или** T0=… T1=… (сколько дней между): …

**Оркестрация**

- [ ] Галочек за часовой блок (если был): …
- [ ] Сколько раз за день писал строку состояния перед сменой агента (примерно): …

**Контекст**

- [ ] Утечки сегодня (Telegram, Instagram, почта, телефон): …
- [ ] Усталость утро / вечер (1–10): … / …

## Напоминание

Параллельные агенты — норма. Считаем **утечки** и **потерю карты задач**, не смену агента A→B.
